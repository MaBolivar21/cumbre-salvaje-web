# Arquitectura pública de Cumbre Salvaje

## Separación de superficies

- **cumbresalvaje.mx** — sitio público institucional/comercial.
- **go.cumbresalvaje.mx** — Cumbre GO, cotizador y constructor de experiencias.
- **go.cumbresalvaje.mx/admin** — CRM interno.

## Regla de conversión

La web no replica el cotizador. Su función es inspirar, explicar y dirigir a Cumbre GO.

Todos los CTA comerciales principales deben apuntar al enlace canónico:

`https://go.cumbresalvaje.mx/`

La selección de Pareja, Familia, Amigos, Escuela o Empresa ocurre dentro de Cumbre GO.
